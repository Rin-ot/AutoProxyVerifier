# Proxy Auto Authenticator

学内LANや公衆Wi-Fi環境などで発生する、一定時間ごとのプロキシ認証（キャプティブポータル認証）切れを自動で回避するためのWindows常駐型アプリケーションです。

バックグラウンドで定期的に認証リクエストを送信し、セッションを維持することで、プロキシ認証情報を保存できない一部のアプリケーションの通信切断を防ぎます。

## ✨ 特徴 (Features)

* **タスクトレイ常駐:** メインウィンドウを持たず、タスクトレイ（システムトレイ）で静かにバックグラウンド動作します。
* **柔軟なプロキシ設定:** Windowsのシステムプロキシ設定をそのまま流用できるほか、アプリ単独で明示的にプロキシのURIやプロトコル（HTTP, HTTPS, SOCKS4, SOCKS5）を指定可能です。
* **カスタマイズ可能な更新間隔:** 環境のタイムアウト時間に合わせて、1分から60分の間で自動更新の間隔を設定できます。
* **手動認証機能:** タスクトレイアイコンの右クリックメニューから、任意のタイミングで即座に認証リクエストを送信できます。

## 動作環境 (Requirements)

* OS: Windows 10 / Windows 11
* ランタイム: [.NET 8.0 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/8.0) 以上

## 🚀 インストールとビルド (Installation & Build)

開発環境（.NET 8.0 SDK）がインストールされている場合、以下の手順でビルドできます。

1. リポジトリをクローンまたはダウンロードします。
   ```bash
   git clone https://github.com/Rin-ot/AutoProxyVerifier.git
   cd ProxyAutoAuth
   ```

2. 以下のコマンドを実行してビルドします。
  ```bash
  dotnet build -c Release
  ```

3. `bin/Release/net8.0-windows/` フォルダ内に生成された `ProxyAutoAuth.exe` を実行します。

## 使い方 (Usage)

1. `ProxyAutoAuth.exe` を起動すると、タスクトレイに盾のアイコンが表示されます。
2. 初回起動時は自動的に設定画面が開きます。以下の項目を設定してください。
* **ユーザー名:** プロキシの認証ID
* **パスワード:** プロキシの認証パスワード
* **更新間隔:** 認証が切れる少し前の時間を設定してください（デフォルト: 30分）
* **プロキシ種類:** 基本は `System`（Windowsの設定に従う）を選択。個別に指定する場合は `HTTP`, `SOCKS5` などを選択。
* **アドレス:** `System` 以外を選択した場合、`proxy.example.com:8080` の形式で入力。


3. 「保存」をクリックすると、設定された間隔で自動的に認証リクエスト（`http://captive.apple.com/hotspot-detect.html` 宛）がバックグラウンドで送信されるようになります。

### メニュー操作

タスクトレイのアイコンを右クリックすると、以下の操作が可能です。

* **認証を今すぐ実行:** 即座に認証リクエストを送信します。
* **設定:** 設定画面を開きます。
* **終了:** アプリケーションを完全に終了します。
